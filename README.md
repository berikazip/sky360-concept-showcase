# Sky360 B2C concept — visual showcase

Static snapshots of the redesigned Sky360 B2C site (concept layer), captured from the
running app at 1440px. **Visual only** — no APIs, no booking logic; links move between
the captured pages, dropdowns and forms are inert.

Pages: home (EN + Hebrew RTL), packages results, flights results, package detail,
attractions results + detail, destinations, contact, checkout, cart drawer, date picker.

Source of the real implementation: `skygroup-react` (`packages/b2c`, concept layer under
`src/assets/styles/concept` + `src/concept`).
